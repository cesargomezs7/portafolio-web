# portafolio-web — Pronto

Repositorio público de [Pronto](https://prontoweb.co) (agencia web para clínicas dentales colombianas).

## Contenido

- **`pronto.html`** — landing pública oficial (live en `prontoweb.co`)
- **`script-ventas.html`** — script interno de ventas
- **`privacidad.html`** — política de privacidad (requerida por Meta WhatsApp Business)
- **`cirugia-oral.html`** — template base del que derivan las demos personalizadas por clínica
- **`demos/`** — 954 demos HTML personalizadas para outreach
- **`mvps/`** — MVPs showcase del Plan Esencial y Plan Completo
- **`clientes/`** — (vacío) webs de clientes reales activos
- **`_scripts/`** — utilidades para crear nuevas webs de cliente en <2 horas

## Modelo de negocio

Suscripción mensual pura:
- **Pronto Esencial:** $199.900 COP/mes
- **Pronto Completo:** $399.900 COP/mes
- Primer mes 100% gratis, sin contratos, cancelación libre
- Cobro vía Mercado Pago Suscripciones Colombia

Stack técnico: GitHub Pages + Umami Cloud + WhatsApp Business API + Notion + bridge Node.js propio.
